My To-Do List Website

A simple, modern, and responsive To-Do List Web App where you can add tasks, mark them as complete, filter tasks, and store everything locally in your browser — so your tasks stay even after refreshing the page 

Features

✔ Add tasks
✔ Optional due date for each task
✔ Mark tasks as completed / active
✔ Filter tasks:

All

Active

Completed

✔ Delete tasks
✔ Clear all completed tasks
✔ Tasks are saved automatically using localStorage
✔ Mobile-friendly responsive UI
✔ Clean and modern design

🗂 Project Structure
todo-list-website/
│
├── index.html      → Main webpage
├── style.css       → Styling / UI design
└── script.js       → App logic & browser storage

How to Run
Open Locally

Download the project files

Make sure the three files are in the same folder

Double-click index.html

Done
